# 无动画 HTML 演示文稿统一契约设计

日期：2026-08-03
状态：设计方向已确认，待书面规格审阅

## 1. 背景与目标

根 `SKILL.md` 已将本项目定义为“在遵循品牌规范的基础上创建无动画 HTML 演示文稿”。当前项目的品牌源、同步生成器、生成文件、模板设计文档和插件镜像仍包含动效时长、缓动、入场、循环动画及降级规则，导致权威目标与实际生成契约不一致。

本次修改以根 `SKILL.md` 为权威，将“无动画”落实为完整静态契约：生成的演示文稿不得包含装饰性动画或过渡，同时保留导航、触摸切页、页码更新、编辑、自动保存、保存 HTML 和打印等功能性交互。

## 2. 范围

### 2.1 纳入范围

- 根 `SKILL.md` 中与动效资源、动效令牌、动效强调和降级行为有关的规则。
- `brand/source.json` 中的画布、配色与其他品牌源配置。
- `scripts/sync-brand.py` 的校验、生成、同步和插件镜像逻辑。
- `brand/generated/` 下由同步脚本生成的规则和 CSS 令牌。
- `html-template.md` 和 `viewport-base.css` 中的演示文稿基础样式。
- 七种模板的 `design.md`，以及经检查存在主动动效指令的模板 `preview.md`。
- 根目录与插件目录之间的受管镜像。
- `tests/` 中覆盖品牌同步、静态契约和运行时能力的测试。
- `scripts/export-pdf.sh` 中仅为等待动画而存在的注释或延时；若延时用于字体、图像或打印渲染稳定，则保留并按真实用途改名。

### 2.2 不纳入范围

- 不删除键盘、按钮、触摸导航或当前页状态更新。
- 不删除内容编辑、自动保存、下载 HTML 或打印能力。
- 不改变 750 × 1320 固定舞台、整体视口缩放或现有品牌排版体系。
- 不禁止正文在语义上描述“运动”“移动”“流动”等现实过程；只禁止将其写成演示文稿的视觉动效规则。
- 不重新设计模板布局或色调；品牌配色始终由 `brand/source.json` 统一提供。

## 3. 设计决策

### 3.1 品牌源不再声明动效

从 `brand/source.json` 删除 `motion` 配置。静态演示不再保留 `0ms` 形式的伪动效令牌，也不再把动效作为品牌规则的一部分。

这样可以让数据模型直接表达真实约束：项目没有可供模板消费的动效值，而不是保留一组理论存在但始终被覆盖的参数。

### 3.2 同步生成器停止生产动效资产

`scripts/sync-brand.py` 将：

- 不再要求或读取 `motion` 字段。
- 不再生成 `--brand-motion-*` CSS 自定义属性。
- 不再生成或镜像 `animation-patterns.md`。
- 不再输出幻灯片入场、元素显现、循环效果或 `prefers-reduced-motion` 动效降级规则。
- 在检查模式下验证源、生成文件和插件镜像均符合静态契约。

`animation-patterns.md` 的根目录版本和插件镜像版本将删除。删除属于 Git 可恢复变更，可从修改前提交回滚。

### 3.3 基础样式采用即时状态切换

`html-template.md`、生成的 `viewport-base.css` 及相关生成规则不再包含装饰性 `animation`、`@keyframes` 或 `transition`。幻灯片显示状态和控制状态仍可通过类名、属性和事件切换，但视觉结果即时生效。

功能性交互与视觉动画分离：JavaScript 仍负责改变当前页、更新计数、响应触摸和键盘、处理编辑与持久化；CSS 不为这些状态变化添加补间、淡入、位移或循环效果。

### 3.4 模板文档改为静态构图语言

七种模板的 `design.md` 将删除或重写主动动效指令，包括但不限于：

- 入场动画、淡入、滑入、缩放或交错显现。
- 自动循环、脉冲、漂浮、闪烁、星空移动和粒子运动。
- 动画触发条件、持续时间、缓动和延迟。
- 仅在减少动态偏好下关闭效果的降级规则。

原本用于表达信息顺序的内容改写为静态层级、阅读路径、构图节奏或多页展开规则。例如“依次出现三个证据点”改为“按明确的阅读顺序排列三个证据点”。物理过程本身的语义描述不作机械删词。

### 3.5 根文件与插件镜像保持单源同步

根目录继续作为权威来源，插件目录只保留同步生成的镜像。不得手工只修改一个副本。同步脚本负责将根 `SKILL.md`、品牌生成文件、基础模板和模板文档复制到插件镜像，并在 `--check` 模式下报告缺失、过期或多余的受管文件。

若某个已删除的动效文件仍残留在插件镜像中，检查应失败，而不是把残留文件视为无关文件。

## 4. 数据流

```text
brand/source.json（无 motion）
        │
        ▼
scripts/sync-brand.py
        ├── brand/generated/brand-rules.md
        ├── brand/generated/brand-tokens.css（无动效令牌）
        ├── viewport-base.css（无动画或过渡）
        └── 插件镜像（与根受管文件一致）

所选模板 preview.md / design.md
        │
        ▼
静态布局、节奏、信息层级和配色规则
        │
        ▼
无动画 HTML 演示文稿
        └── 保留导航、编辑、保存与打印
```

## 5. 校验与错误处理

同步检查应能识别以下契约漂移：

- `brand/source.json` 重新出现 `motion` 配置。
- 生成 CSS 重新出现品牌动效令牌、关键帧、动画声明或过渡声明。
- 根目录或插件镜像重新出现受管的 `animation-patterns.md`。
- 模板设计规则重新出现明确的主动动画章节或已知装饰动效指令。
- 根文件与插件镜像不一致。

检查不得使用对“motion/运动”等单词的全局禁用，因为这会误伤内容语义。校验应针对配置字段、CSS 属性、资源文件和明确的生成指令。

遇到不符合静态契约的源文件时，同步脚本应在检查模式返回非零状态并给出具体文件或规则；正常同步模式只更新其明确管理的文件，不改写无关内容。

## 6. 测试优先实施策略

实施时先添加能在当前代码上失败的测试，再修改生产代码：

1. 品牌源测试：断言 `brand/source.json` 不含 `motion`。
2. 生成资产测试：断言生成 CSS 不含 `--brand-motion-*`、`animation`、`@keyframes` 或 `transition` 契约。
3. 资源生命周期测试：断言同步器不再生成 `animation-patterns.md`，并能识别根目录或插件镜像中的残留受管副本。
4. 模板契约测试：断言七种模板不再包含明确的主动动画章节和已知装饰性动效指令；测试目标为可执行规则，不对普通内容词汇做全局搜索。
5. 镜像一致性测试：断言根目录与插件受管副本同步。
6. 功能回归测试：验证导航、编辑、保存和打印相关运行时契约仍然存在。

先运行新增的定向测试确认其因旧动效行为而失败；随后完成最小实现使其通过；最后运行全量验证。

## 7. 验收标准

- 根 `SKILL.md` 只描述无动画生成流程，不再加载或引用动效资源与动效令牌。
- `brand/source.json` 不含动效参数，且同步生成器不期待该字段。
- 根生成文件和插件镜像不含动效令牌、主动动画规则或 `animation-patterns.md`。
- 七种模板仍保留各自的静态视觉特点，但不指导生成入场、循环或装饰性过渡。
- 导航、触摸切页、页码、编辑、自动保存、保存 HTML 和打印能力保持可用。
- 以下用户指定命令通过：

  ```powershell
  python scripts/sync-brand.py --check
  python -m unittest discover -s tests -v
  ```

- 额外运行项目已有的运行时校验，以证明保留的非装饰性交互未回退：

  ```powershell
  npm run validate:runtime
  ```

## 8. 回滚边界

本次只修改仓库内受管文本、脚本、测试和生成资产，不触碰外部系统。所有删除和重写均由 Git 跟踪；若最终效果不符合预期，可回滚实现提交。书面设计规格独立提交，便于保留决策记录或单独撤销。
